 EXOMISER (family mode) is skipped when familyPheno is not provided, SLIVAR when familyPed is not.
 A proband is a PED affected child (affected, with a parent in the PED) that has its own
 per-sample row, decided from the samplesheet (isPedProband). A family with a proband gets no
 family-level VEP or SLIVAR: its CNVs that only the parents carry stay in depth_refined/.
 Family-mode EXOMISER runs on a proband's SLIVAR VCF when the familyPheno phenopacket is about
 that proband (proband.subject.id), and on the family (or joint) VCF otherwise.


RESTORE_COLLAPSED_FORMAT in detail (bin/restore_collapsed_format.py)
════════════════════════════════════════════════════════════════════

truvari collapse copies an absorbed call's FORMAT into the kept record only when it reads that
call's GT as set: DRAGEN's ./1 (gain of unknown zygosity) and haploid 1 (a male's chrX) read as
unset, so they were dropped. Example: a real chr10 cluster of the NA12878 trio.

 INPUT 1: truvari collapse -o  (kept records)                INPUT 2: truvari collapse -c  (removed = absorbed calls)
 ─────────────────────────────────────────────               ───────────────────────────────────────────────────────
 chr10:38954276  NA12891's gain                               NA12892's gain   MatchId=1.0  TruScore=60
 INFO  CollapseId=1.0  NumConsolidated=0                        NA12878 ./.        NA12891 ./.     NA12892 ./1:CN3:OID_C
 FORMAT                                                       NA12878's gain   MatchId=1.0  TruScore=56
   NA12878  ./.:.:.          <- empty                           NA12878 ./1:CN3:OID_A  NA12891 ./.     NA12892 ./.
   NA12891  ./1:3:OID_B      (truvari's kept call)
   NA12892  ./.:.:.          <- empty                         (truvari left both out: it reads ./1 as unset)
            │                                                            │
            │                                                            ▼
            │                                ┌────────────────────────────────────────────────────┐
            │                                │ 1. index the absorbed calls by MatchId             │

            │                                │               (56, {NA12878: FORMAT_A}) ]          │
